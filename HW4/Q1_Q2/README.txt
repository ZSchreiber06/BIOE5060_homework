The grow function can intake a user-given number of iterations and a user-defined mask. Then for each iteration, it uses conv2() to translate the center pixel of the mask over each pixel of the image and update the center mask pixel as the maximum value of the center pixel's neighbors. Next, it uses logical() to convert the new matrix to a logical matrix (so it is only ones and zeros) and replace the self.image0 with the new matrix for future iterations.

The shrink function is the opposite of the grow function. This is achieved by taking the inverse of the image, inputting that into the grow function, and then inverting the output back. Thus achieving the same as translating the center pixel of the mask over each pixel of the image, updating the center mask pixel to the MINIMUM value of the center pixel's neighbors.
